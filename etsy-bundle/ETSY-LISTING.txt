📊 7-Tab Spreadsheet (CSV Pack for Google Sheets / Excel):

• Dashboard — Side-by-side contractor summary; auto-flags the lowest bid (sage
  green) and top scorer (terracotta) so the right choice jumps out immediately
• Bid Comparison — 10 contractor rows with expiry-date alerts and outlier flags
  on materials vs. labor costs
• Contractor Scoring — Weighted scoring engine (Price 30% / Timeline 20% /
  Communication 20% / References 20% / Gut Feel 10%) with auto-rank
• License & Insurance Verification — Track contractor license, general
  liability, and workers' comp expiry dates with automatic status flags
• Reference Check Log — 30 pre-loaded rows (3 per contractor) with quality
  ratings and per-contractor average summary
• Contract Checklist — 10-item pre-signing checklist with completion tracker
  and status indicator
• Instructions — Plain-English homeowner guide: what to do, in what order

🖨 Printable Workbook (HTML → Save as PDF in any browser):

2. File → Import → Upload → select 01_Dashboard.csv
3. Import location: "Insert new sheet(s)" | Separator: Comma | Convert: Yes
4. Repeat for each CSV file (tabs 01–07)
5. Open the formula reference sections and paste the formulas into cells

Microsoft Excel:
1. File → Open → Browse → select each CSV file
2. Rearrange tabs in the order 01 → 07
3. Paste the formulas from the FORMULA REFERENCE sections

❓ FAQ

Q: Does this work with Microsoft Excel?
A: Yes. Open each CSV with File → Open in Excel. Formulas are included as
   paste-ready text in a "FORMULA REFERENCE" section at the bottom of each tab.

Q: Can I use this for any type of renovation project?
A: Absolutely — kitchen, bath, roof, HVAC, flooring, full remodel, addition.
   The template is project-type neutral.

Q: How many contractors can I track?
A: Up to 10 contractors across all tabs. The reference log has 30 rows (3
   references per contractor).

Q: Do I need to pay for Google Sheets?
A: No. Google Sheets is free with any Google account at sheets.google.com.

Q: What if I only have 3 or 4 contractors?
A: Just fill in the rows you need and leave the rest blank. Formulas handle
   empty rows gracefully.

Q: Can I customize the scoring weights?
A: Yes — the formula reference section shows the weighted-score formula. Change
   the multipliers (0.30, 0.20, etc.) to match your priorities.

Q: Is this a physical item?
A: No — this is an instant digital download. You'll receive the files
   immediately after purchase.
