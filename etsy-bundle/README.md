## Quick Start

### Option A — Google Sheets / Excel (Digital Spreadsheet)

1. Open `csv/00_README_Import_Instructions.txt` for step-by-step import guide.
2. Import each numbered CSV file as a separate tab.
3. Paste the formulas from the FORMULA REFERENCE sections into the appropriate cells.
4. Fill in your project details and contractor bids.

### Option B — Printable PDF Workbook

1. Open `printable/Contractor-Bid-Tracker-Printable.html` in Chrome or Safari.
2. Click the **"Print / Save as PDF →"** button in the top-right corner.
3. In the print dialog: select **"Save as PDF"**, paper size **Letter**, margins **Default**.
4. Print the sections you need — bid sheets, reference check forms, checklist.

## Tab Overview

| Tab | Purpose |
|-----|---------|
| 01 Dashboard | Project overview and side-by-side contractor summary |
| 02 Bid Comparison | Collect and compare bids from up to 10 contractors |
| 03 Contractor Scoring | Weighted scoring system to rank every bid objectively |
| 04 License & Insurance | Track expiry dates and verification status |
| 05 Reference Check Log | Log up to 3 reference calls per contractor (30 rows total) |
| 06 Contract Checklist | 10-item pre-signing checklist to protect yourself |
| 07 Instructions | Plain-English guide for first-time users |

---

## Scoring Weights

The Contractor Scoring tab uses this weighting system (100 points total):

- **Price** — 30 pts (auto-calculated from bids)
- **Timeline** — 20 pts (enter manually after interviews)
- **Communication** — 20 pts (enter manually after interviews)
- **References** — 20 pts (enter manually after reference calls)
- **Gut Feel** — 10 pts (your subjective impression)
